## 更新日志

### 版本 2.3.0 (2026-05-13)

#### ✨ 新增功能
- **笔记风格选择**：交互配置中新增三种笔记风格：
  - **论述型**（默认）：保留原文论证脉络，重构为连贯的学术综述
  - **结构化型**：模块化整理，强调概念层次与关联，适合系统学习
  - **极简型**：提取核心要点，简洁 bullet points，适合快速复习
- **大纲先行（长文档）**：当原文超过 6000 字符时，程序先让 AI 生成内容大纲，经用户确认或修改后再生成全文，避免长文档输出碎片化。
- **强制笔记骨架**：三种风格均配有强制输出结构：
  - 论述型：核心论点总览 → 章节脉络 → 分节详细论述 → 跨节关联总结
  - 结构化型：知识框架概览 → 章节脉络 → 分模块详细整理 → 体系化总结
  - 极简型：核心要点概览 → 分节要点 → 总结
- **结构级修订**：修订环节新增"结构级调整"选项，支持一键修复：
  - 太碎片化 → 加强连贯性
  - 缺少关联 → 补充概念间逻辑关系
  - 篇幅失衡 → 重新调整比例
  - 太冗长 → 精简聚焦
  - 太浅显 → 加深分析

#### 🔧 功能增强
- **AI 提示词重构**：`ai_client.py` 全面重构，`_build_latex_system_prompt()` 和 `_build_markdown_system_prompt()` 根据风格动态生成 prompt，确保输出风格一致性。
- **风格记忆**：`note_style` 纳入 `config.json` 统计，常用风格会在预设中自动推荐。
- **修订风格一致性**：`revise_content()` 新增 `note_style` 和 `structural_issue` 参数，修订时保持原风格不变。

#### 📄 文档
- 重写 README.md：突出笔记风格、大纲先行、结构级修订三大核心功能，重新组织结构。
- 重写 QUICKSTART.md：补充笔记风格在关键设置和完整配置中的说明，完善修订环节的操作指引。
- 新增 `.env.example`：提供完整的环境变量配置模板。

### 版本 2.2.0 (2026-05-13)

#### ✨ 新增功能
- **混合 API 架构**：文本生成迁移回 DeepSeek `deepseek-chat`，视觉 OCR 改用阿里云百炼 `qwen-vl-max`，兼顾文本质量与图像识别能力。
- **批量处理模式**：支持一次处理多个文件，统一配置、分别输出到独立 `Article_X/` 目录，自动跳过多轮修订与打分。
- **自定义 LaTeX 模板**：支持用户上传自己的 `0_main_<名称>.tex` 和 `headerfooter_<名称>.tex` 到 `Template/custom/` 目录，程序自动检测并供选择。
- **模板宏包感知**：自动读取模板中已加载的宏包列表，在生成笔记时告知 AI 可用哪些宏包，避免使用未加载宏包导致编译失败。
- **AI 输出后处理**：新增 `extract_latex_body()` 过滤器，自动剔除 AI 输出的 markdown 代码块标记、说明文字、`<thinking>` 思维链等包装内容。

#### 🔧 功能增强
- **模板系统重构**：`template_filler.py` 从孤立工具升级为输出管理中心，统一处理模板填充、草稿保存、最终输出。
- **PPTX OCR 增强**：修复 base64 data URL 的 MIME 类型硬编码问题；支持递归提取 GroupShape 内图片；模式 2 下优先使用视觉描述理解图表结构。
- **文本生成长度保障**：所有文本生成 API 调用统一设置 `max_tokens=8192`，避免输出被截断为一句话。
- **命令行参数**：新增 `--batch` 启用批量处理模式。

#### 🐛 修复
- 修复 `load_dotenv()` 导入顺序问题，确保 `.env` 在模块级变量读取前已加载。
- 修复千帆 `deepseek-ocr` 模型名 404 错误，改为百炼 `qwen-vl-max`。
- 修复 Qwen 输出包装内容混入 `.tex` 文件导致的编译错误。

#### 📄 文档
- 更新 README.md，反映混合 API 架构、批量处理、自定义模板等新功能。
- 更新 QUICKSTART.md，补充批量处理流程和自定义模板使用说明。

### 版本 2.1.0 (2026-05-13)

#### ✨ 新增功能
- **DeepSeek-OCR 视觉描述**：对扫描件/手写笔记 PDF，支持直接调用千帆 DeepSeek 视觉模型进行"页面内容描述"，而不仅仅是文字提取，大幅提高复杂排版和手写体的理解能力。
- **OCR 模式分级**：交互配置中新增 OCR 模式选择：
  - 模式 1（默认）：仅对 pdfplumber 提取为空的页面启用 OCR。
  - 模式 2：对所有页面启用视觉描述 + OCR 补充，适合处理全面扫描/手写笔记。
  - 直接回车：完全关闭 OCR。
- **视觉描述有效性校验**：自动判断视觉描述是否包含实质内容，若无效则自动回退到普通 OCR 文字提取，避免 AI 收到空数据后产生幻觉。
- **OCR 调试信息**：终端会显示每页 OCR/视觉描述的调用状态和结果（成功/回退/失败），便于排查问题。

#### 🔧 功能增强
- **OCR 引擎切换**：正式移除旧的百度通用 OCR（`general_basic`），统一改用千帆 DeepSeek-OCR 接口，兼容 OpenAI 格式。
- **PPTX 提取保留原样**：PPTX 仍使用原生文字提取，暂不支持 OCR，终端提示保持不变。
- **环境依赖更新**：`.env` 中新增 `QIANFAN_API_KEY`，原 `OCR_API_KEY` 和 `OCR_API_SECRET` 不再使用。
- **提示词优化**：在手写/扫描模式下，提示词会引导 AI 基于视觉描述整理笔记，并抑制幻觉。

#### 🐛 修复
- 修复了 OCR 调用无日志输出的问题，现在会明确提示 `pdf2image` 未安装或 Poppler 缺失。
- 修复了满意度反馈在部分流程中被跳过的 bug。
- 修复了 Markdown 模式下作者/日期字段缺失的问题。

#### 📄 文档
- 更新 README.md，增加 DeepSeek-OCR 配置说明和视觉描述使用方式。
- 补充 OCR 调试信息和常见问题排查。
