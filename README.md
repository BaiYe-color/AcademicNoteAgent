# AcademicNoteAgent
一个基于大语言模型（DeepSeek）的命令行智能体，能够将 PDF 讲义或 PPT 演示文稿自动整理为结构清晰、包含引言与总结的学术笔记，并输出可直接编译的 LaTeX 文件。  
该项目具备**自主感知、记忆学习、多轮交互修订、断点续传、彩色终端界面**等能力，是一个面向学术写作的智能笔记助手。

---

## 🧠 Agent 核心特征

| Agent 特性 | 实现方式 |
|-----------|----------|
| 📡 **感知环境** | 自动扫描 `Source/` 目录，列出所有 PDF/PPTX 并支持手动选择；提取文本；可选 AI 学科识别。 |
| 🧠 **决策推荐** | 根据历史使用统计，自动推荐用户最常用的字体、字号、封面等格式，确认后直接采用。 |
| 🛠️ **自主执行** | 调用 DeepSeek 模型将原始材料整理为结构化 LaTeX 笔记（引言＋正文＋总结），并自动修正语法错误。 |
| 📚 **记忆学习** | 配置文件 `config.json` 记录每次的格式选择、学科偏好、用户反馈；高分反馈会注入后续 prompt，逐步调优输出。 |
| 🔄 **多轮交互** | 生成初稿后，用户可连续提出修改意见，AI 逐轮修订并保存多个草稿；支持最多 5 轮修订。 |
| ⏸️ **断点续传** | 修订过程中可随时中断，下次运行时自动检测未完成任务，从断点继续修改，无需重头开始。 |
| 🎨 **彩色进度界面** | 采用 `rich` 库提供彩色状态提示、进度条、面板等，操作过程清晰美观。 |

---

## 🚀 主要功能一览

- 📥 **多格式输入**：支持 `.pdf`（通过 pdfplumber）和 `.pptx`（通过 python-pptx）。
- 🧠 **AI 笔记生成**：调用 DeepSeek‑Chat 模型，生成包含引言、层级正文、总结的结构化 LaTeX 笔记。
- 🔍 **反思与自我修正**：自动检查并修复常见 LaTeX 语法错误（表格列数、括号配对、特殊字符转义等）。
- ✍️ **多轮交互修订**：每轮修订保存一份独立草稿，用户可逐轮对比、回溯修改。
- 📂 **智能文件选择**：若不指定输入文件，自动列出 `Source/` 中所有文件供选择，并显示文件大小和创建时间。
- 🎨 **精细格式定制**：交互式选择中英文字体（衬线/无衬线/等宽）、字号、封面、页眉页脚等。
- 🧑‍🔬 **学科自动识别**：可选让 AI 识别材料所属学科，并记录学习偏好。
- 💬 **满意度反馈与学习**：每次生成后收集评分与建议，高分反馈会融入下一次生成，逐步贴合用户风格。
- 📊 **个性化预设**：系统统计常用字体、封面等选项，下次可一键使用最常用配置。
- 📁 **自动编号与草稿管理**：每次处理创建 `Article_X` 目录，支持多轮草稿保存与最终清理。
- 🎥 **彩色终端输出**：进度条、状态图标、彩色面板，操作反馈一目了然。

## 🛠️ 安装与配置

### 1. 环境要求

- Python 3.8 及以上
- 完整的 TeX 发行版（如 TeX Live 或 MiKTeX，需支持 XeLaTeX）

### 2. 安装依赖

```bash
git clone <your-repo-url>
cd project
pip install -r requirements.txt
```

`requirements.txt` 内容：
```
pdfplumber
openai
python-dotenv
python-pptx
rich
```

### 3. 配置 API Key

复制环境变量模板并填入你的 DeepSeek API Key：

```bash
cp .env.example .env
```

编辑 `.env` 文件：
```
DEEPSEEK_API_KEY=sk-your-key-here
```

### 4. 准备 LaTeX 模板

在 `Template/` 目录下放置两个文件：

- `0_main.tex`：主文档模板，包含 `<<FONT_SIZE>>`、`<<CJK_MAIN_FONT>>`、`<<DOC_TITLE>>`、`<<COVER_COMMAND>>` 等占位符。
- `headerfooter.tex`：页眉页脚模板，包含 `<<HEADER_LEFT>>`、`<<HEADER_CENTER>>`、`<<HEADRULE_WIDTH>>` 等占位符。

> 项目中已提供默认模板，开箱即用。

## ⚡ 快速开始

将待处理的 PDF 或 PPTX 文件放入 `Source/` 目录，然后运行：

```bash
python main.py
```

程序会自动列出 `Source/` 中的所有文件，选择文件后进入智能处理流程。

## 📖 详细使用流程

### 1. 启动方式

- **自动扫描与选择（推荐）**：
  ```bash
  python main.py
  ```
  列出 `Source/` 中所有 PDF/PPTX 文件（含大小和创建时间），输入序号选择文件，回车确认。

- **指定文件**：
  ```bash
  python main.py --file "Source/我的讲义.pdf"
  ```

### 2. 交互式配置

程序会依次询问：

1. **是否进入格式选择**：回车使用默认格式，输入任意键进入自定义。
2. **字体选择**：中文衬线、中文无衬线，西文衬线、西文无衬线、西文等宽（每步可直接回车使用默认）。
3. **正文字号**：输入 8～20 的数字，回车使用 12pt。
4. **封面设置**：是否生成封面；若选择“是”，可自定义标题、作者、日期（或让 AI 自动生成标题）。
5. **页眉设置**：是否生成页眉；若选“是”，可分别输入左、中、右页眉文字。
6. **内容类型**（可选）：1-理论笔记 / 2-案例分析 / 3-实验报告 / 4-数据手册（回车自动识别）。
7. **学科识别**：是否让 AI 识别材料学科（默认跳过）。

> 如果你已经多次使用本工具，系统会记住你的偏好，启动时会提示：“检测到您的常用格式为：宋体、12pt、无封面。是否直接使用？”直接回车即可跳过所有手动配置。

### 3. 自动处理

- 📄 显示进度条提取文本 → （可选）AI 识别学科 → （可选）AI 自动生成标题
- 🤖 调用 DeepSeek 生成结构化学术笔记（引言 + 正文 + 总结）
- 🔧 自动进行 LaTeX 语法检查与修正（可通过 `--no-reflect` 跳过）

### 4. 多轮交互修订

初稿生成后，系统提示：

```
笔记初稿已保存到 draft_01。是否需要继续修改？输入 1 进入修改，输入 0 结束并生成最终稿。
```

- **输入 1**：可输入具体的修改意见，例如：
  - “请把引言改写得更简洁”
  - “增加一个对比表格”
  - “用更学术的语言重写总结”
- AI 根据意见重新生成 `content.tex`，并保存为新的草稿 `draft_02`、`draft_03` ……
- 可反复修改，最多 5 轮。
- **输入 0**：结束修订，生成最终稿。

### 5. 断点续传（休眠唤醒）

如果在多轮对话修订过程中程序被中断（如按 Ctrl+C 或意外关闭），下次运行 `python main.py` 时，会检测到未完成的任务：

```
检测到上次未完成的笔记任务。
是否从上次中断处继续？(回车确认，输入 no 则重新开始)
```

- 确认后直接进入修订环节，保留之前的所有草稿和配置，无需重新生成。
- 若选择重新开始，则会清除旧状态，从头处理。

### 6. 生成最终稿

退出修订循环后，系统会将最后版的内容（以及对应的 `main.tex`、`headerfooter.tex`）复制到 `Article_X/` 根目录，并删除所有 `draft_*` 子文件夹，只保留干净的可编译文件。终端会显示绿色成功信息和文件路径。

### 7. 编译生成 PDF

进入输出目录，使用 XeLaTeX 编译：

```bash
cd Result/Article_1
xelatex main.tex
```

### 8. 满意度反馈

最终稿生成后，可对本次笔记打分（1-5）并留下修改建议。高分反馈会被记录，并在你下次生成笔记时自动融入提示词，持续改善生成效果。

## ⌨️ 命令行参数

| 参数 | 说明 |
|------|------|
| `--file <path>` | 指定待处理的 PDF 或 PPTX 文件路径（支持空格，建议用引号）。若不提供则列出 `Source/` 目录下所有文件供选择。 |
| `--no-reflect` | 跳过自我修正环节（不进行 LaTeX 语法自动修复）。 |
| `--no-revise` | 跳过交互修订，直接使用初稿作为最终稿（不创建草稿目录）。 |
| `--reset-config` | 重置配置文件 `config.json` 为默认值，下次运行重新生成。 |

## 💾 配置与状态文件

### `config.json`

自动生成，结构如下：

```json
{
  "presets": {
    "cjk_serif": "SimSun",
    "cjk_sans": "SimHei",
    ...
  },
  "usage_stats": {
    "cjk_serif": { "SimSun": 5, "KaiTi": 2 },
    "subject": { "计算机科学": 3, "法学": 1 },
    ...
  },
  "feedback_history": [
    { "score": 4, "comment": "多使用表格" },
    ...
  ]
}
```

- `presets`：常用格式（由系统自动根据统计更新）
- `usage_stats`：各选项使用次数，用于个性化推荐
- `feedback_history`：最近 5 条评分与建议（高分反馈会注入后续生成）

### `session_state.json`

仅在多轮修订过程中存在，记录当前草稿编号、文件内容等。任务完成或被重置后自动删除。

## ❓ 常见问题

### 1. 编译 LaTeX 时报错
- 确保已安装完整 TeX 发行版并支持 XeLaTeX。
- 确认模板中指定的中文字体（如 SimSun、SimHei）在系统中可用，或通过交互配置选择已安装字体。
- 表格报错通常是列数不匹配导致，生成的 `content.tex` 中已自动修复多数问题，若仍有误可手动检查。

### 2. API 调用失败
- 检查 `.env` 中的 `DEEPSEEK_API_KEY` 是否正确。
- 确保网络可访问 `api.deepseek.com`。

### 3. 如何删除所有草稿重新开始？
- 直接删除 `Result/` 下对应 `Article_X` 文件夹，或使用 `--reset-config` 重置配置文件后重新运行。

### 4. 为什么有时不问我是否继续修改？
- 如果使用了 `--no-revise` 参数，将跳过交互修订。
- 如果从断点恢复，会自动进入修订环节以便继续之前的工作。

### 5. Source 中有多个文件时如何选择？
- 不带 `--file` 运行程序，会列出所有文件及其大小和创建时间，输入序号即可。
